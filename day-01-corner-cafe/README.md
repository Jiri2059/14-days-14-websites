# Window Seat — Day 01

A standalone one-page website for a fictional neighborhood café. This is the first project in the **14 Days, 14 Websites** challenge.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. The site has no build step or third-party runtime dependencies.

## What works

- Menu filters for coffee, bakery and brunch items
- Responsive navigation on small screens
- Table enquiry opens an email draft (there is no fake form submission)
- Keyboard focus states and reduced-motion support

All business details, menu items, prices and contact information are fictional concept content.
